개인정보처리방침

시행일: 2026년 10월 12일  |  앱: 배달 자동화 (kr.deliveryauto.app)

배달 자동화(이하 "앱")는 배달 업무 중 내비게이션 자동 전환, 음악 자동 제어, 주문 알림 자동 열기 기능을 제공합니다. 본 방침은 앱이 수집하는 정보와 그 사용 목적을 설명합니다.

1. 수집하는 정보

앱은 외부 서버로 어떠한 개인정보도 전송하지 않습니다. 모든 데이터는 기기 내부에만 저장됩니다.

기기 내부에 저장되는 정보
  • 앱 전환 기록 (배달앱 진입/이탈 시각)
  • 내비게이션 앱 호출 내역 (목적지 좌표, URI 스킴)
  • 배달 앱 알림 수신 기록 (알림 제목, 내용, 채널 ID)
  • 앱 설정값 (선택한 내비게이션 앱, 기능 켜기/끄기 상태)

2. 접근성 서비스 사용

앱은 다음 목적으로만 접근성 서비스를 사용합니다.

  • 배달앱 감지: 배달 앱(배달의민족, 쿠팡이츠 배달파트너)이 화면 전면에 표시될 때를 감지하여 음악을 자동으로 일시정지합니다.
  • 내비게이션 앱 전환: 배달 앱이 내비게이션을 호출할 때 사용자가 선택한 내비게이션 앱으로 자동 전환합니다.
  • 배달지 주소 읽기: 배달 앱 화면에 표시된 배달 목적지 텍스트를 읽어 내비게이션 앱에 전달합니다. 이 정보는 내비 연동 목적으로만 일시적으로 사용되며, 배달 완료 후 즉시 삭제됩니다.

접근성 서비스는 위 목적 이외의 용도로 화면 내용을 수집하거나 외부에 전송하지 않습니다.

3. 알림 수신 권한 사용

앱은 기기의 모든 알림을 읽을 수 있는 권한을 요청합니다. 이 권한은 다음 목적으로만 사용됩니다.

  • 신규 배달 알림 감지: 배달의민족 및 쿠팡이츠 배달파트너 앱의 신규 배달 배정 알림을 감지하여 해당 앱을 자동으로 화면에 표시합니다.

앱은 배달앱 이외의 알림 내용을 저장하거나 처리하지 않습니다.

4. 로그 파일 저장

앱은 동작 기록을 기기 내부 저장소에 텍스트 파일로 저장합니다.

  • 저장 위치: 기기 내부 저장소 (외부 앱에서 접근 불가)
  • 저장 내용: 앱 전환 기록, 내비게이션 호출 기록, 알림 감지 기록
  • 최대 크기: 500KB (초과 시 오래된 기록 자동 삭제)
  • 사용 목적: 오작동 발생 시 원인 파악을 위한 디버깅

로그 파일은 앱 내 "로그 공유" 기능을 통해서만 외부로 내보낼 수 있으며, 자동으로 전송되지 않습니다. 로그 공유 시 배달지 주소 등 개인정보가 포함될 수 있다는 안내가 표시됩니다.

5. 기기 권한 사용

앱은 다음 Android 시스템 권한을 사용합니다.

  • 부팅 시 자동 시작 (RECEIVE_BOOT_COMPLETED): 기기 재시작 후 알림 감지 서비스를 자동으로 다시 연결합니다.
  • 배터리 최적화 예외 (REQUEST_IGNORE_BATTERY_OPTIMIZATIONS): 배달 업무 중 앱이 백그라운드에서 종료되지 않도록 하여, 내비 자동 전환과 음악 제어가 안정적으로 동작하게 합니다.
  • 백그라운드 프로세스 종료 (KILL_BACKGROUND_PROCESSES): 내비게이션 앱 전환 시 이전에 실행된 내비 앱을 정리하여 중복 실행을 방지합니다.

6. 제3자 제공

앱은 수집한 정보를 외부 서버, 광고 플랫폼, 제3자에게 일절 제공하지 않습니다.

7. 정보 보관 및 삭제

  • 앱 설정값은 앱을 삭제하면 함께 삭제됩니다.
  • 로그 파일은 앱 설정 화면에서 직접 삭제할 수 있습니다.

8. 사용자의 권리

  • 언제든지 Android 설정 → 접근성에서 접근성 서비스를 비활성화할 수 있습니다.
  • 언제든지 Android 설정 → 알림 접근에서 알림 리스너 권한을 해제할 수 있습니다.
  • 앱을 삭제하면 모든 저장 데이터가 기기에서 제거됩니다.

9. 아동 개인정보 보호

이 앱은 배달 업무 종사자를 대상으로 하며, 만 14세 미만 아동의 사용을 의도하지 않습니다.

10. 방침 변경

본 개인정보처리방침이 변경될 경우 이 페이지를 통해 공지합니다. 변경 사항은 이 페이지에 게시된 시점부터 효력이 발생합니다.
